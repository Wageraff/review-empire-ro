# Beturi (beturi.ro) — анализ стиля

> Источник: top **20** review-клипов из `01.RAW/web-clips/reviews/` (всего 39 с source beturi.ro).

## Tone

**promo-casual + tu-address**

| Параметр | Среднее по top clips |
|----------|-------------------:|
| Длина | **4,545** слов |
| Предложение | **15.2** слов |
| Абзац | **43.7** слов |
| H2 / clip | **13.4** |
| Списки / clip | **84.3** |

## Обращение к читателю

- **2nd person (tu/poți):** ~65 упоминаний/clip — высокое
- **Imperative (înregistrează, află…):** ~6/clip
- **We-voice (noi/am testat):** ~8/clip
- **Emoji в тексте:** ~6.2/clip

## CTA style

- **Плотность promo-лексики** (bonus, freebet, ofertă, acum): ~87/clip
- **Числа/статы** (RON, %, x): ~182/clip (**40.1**/1000 слов)
- **Таблицы:** ~8 строк/clip

Типичный CTA-паттерн: кнопка-бонус в hero + повтор в секциях.

## Румынские идиомы (частые)

- Клише: «În concluzie», «Este important de menționat»
